# @encap/synthesis-agent

One file in, one OKF bundle out — every claim footnoted to a source with
a page or section anchor, `generated.by` always set. Then the multi-file
case: several documents in, one bundle that is a synthesis, not a
concatenation. In Phase 3 the agent also loads an operating-model bundle
before synthesizing, so it reasons inside the enterprise's doctrine,
structure, and ontology rather than in a vacuum.

Not yet implemented. Built in Phase 2, immediately after `@encap/okf-format`
passes its Phase 1 exit gate. The Phase 2 gate is a competency-question
suite: a bundle passes if an agent reading only its OKF output answers a
fixed set of questions as well as an agent reading the sources, and every
answer cites. Compression ratio is reported but is not the gate. See
`docs/PLAN.md` Section 5 (Phase 2).
